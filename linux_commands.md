# Команды Linux

- pwd — показать путь к текущему каталогу.
- ls — вывести содержимое каталога.
- cd — перейти в другой каталог.
- mkdir -p — создать каталоги и недостающие родительские каталоги.
- echo — вывести строку.
- cat — вывести содержимое файла.
- chmod — изменить права доступа к файлу.
- whoami — показать имя текущего пользователя.
- date — вывести текущую дату и время.
- hostname — показать имя хоста.
- df -h — показать использование дискового пространства.
- find — найти файлы по заданным условиям.
- grep — вывести строки, совпадающие с шаблоном.
